# Rohis SMAN 1 Seputih Mataram - Website

Website resmi Rohis (Rohani Islam) SMA Negeri 1 Seputih Mataram.

## 📁 Struktur Proyek

```
Lagi/
├── index.html          # File utama HTML
├── css/
│   └── style.css      # Semua styling CSS
├── js/
│   └── script.js      # Semua fungsi JavaScript
├── images/            # Folder untuk semua gambar
│   ├── logo.jpg
│   ├── slide-1.jpg
│   ├── slide-2.jpg
│   ├── slide-3.jpg
│   ├── profile-photo.jpg
│   ├── pembina-1.jpg
│   ├── pembina-2.jpg
│   ├── ... (dan gambar lainnya)
│   └── takjil-6.jpg
├── README.md          # File dokumentasi ini
└── LICENSE            # Lisensi proyek
```

## ✨ Fitur

- **Hero Slider** - Slider gambar otomatis dengan navigasi dot
- **Profile Section** - Tentang organisasi Rohis dengan animasi reveal
- **Dewan Pembina** - Scroll horizontal untuk menampilkan daftar pembina
- **Struktur Organisasi** - Tampilan struktur kepengurusan dengan drag-to-scroll
- **Liputan Kegiatan** - Dokumentasi kegiatan dengan gallery scroll
- **Responsive Design** - Desain yang responsive untuk semua ukuran layar
- **Smooth Animations** - Animasi halus dengan CSS dan JavaScript

## 🎨 Teknologi

- **HTML5** - Markup semantik
- **CSS3** - Styling modern dengan Flexbox dan Grid
- **JavaScript (Vanilla)** - Tanpa framework, vanilla JavaScript
- **Google Fonts** - Playfair Display, Montserrat, Lora

## 🚀 Cara Menggunakan

1. **Clone repository**
   ```bash
   git clone https://github.com/ajaatik435-hue/Lagi.git
   cd Lagi
   ```

2. **Tambahkan gambar**
   - Buat folder `images` di root proyek
   - Tambahkan semua gambar sesuai dengan nama di `index.html`

3. **Buka di browser**
   - Buka file `index.html` di browser favorit Anda
   - Atau gunakan Live Server extension di VS Code

## 🔧 Cara Mengedit

### Mengganti Teks
Buka `index.html` dan cari teks yang ingin diganti. Contoh:
- Nama pembina
- Deskripsi kegiatan
- Judul dan tagline

### Mengubah Warna
Edit variabel CSS di `css/style.css`. Contoh:
- `.main-header` untuk warna header
- `.overlay` untuk gradient overlay

### Menambah Gambar
1. Tambahkan gambar ke folder `images/`
2. Update path di `index.html`

## 📝 Catatan

- Semua gambar placeholder (`via.placeholder.com`) perlu diganti dengan gambar asli
- Update nama-nama pembina dan struktur organisasi sesuai data terbaru
- Update deskripsi kegiatan dengan konten yang relevan
